    Solution - Cours 4

    Voici des solutions de référence pour les exercices du cours 4.

    Exercice 1

    A. Coût total des pizzas

    Variables possibles :

    double prixUnitaire = 18.99;
int nbPizzas;
double coutTotal;

    Formule :

    coutTotal = prixUnitaire * nbPizzas;

    B. Temps pour atteindre 400 litres

    Variables possibles :

    double reservoir = 100;
double debit = 12;
double objectif = 400;
double temps;

    Formule :

    temps = (objectif - reservoir) / debit;

    C. Livraison gratuite ?

    Variables possibles :

    double totalAvantTaxes;
bool livraisonGratuite;

    Condition :

    livraisonGratuite = totalAvantTaxes > 70;

    D. Temps avant que Bowser rattrape Mario

    Variables :

    double vitesseMario = 8;
double vitesseBowser = 10;
double avanceMario = 8 * 0.5; // 30 minutes = 0.5 heure
double temps;

    Comme Bowser est plus rapide, on calcule le temps nécessaire pour compenser l’avance :

    temps = avanceMario / (vitesseBowser - vitesseMario);

    Exercice 2

    Console.Write("Vitesse de Mario (km/h) : ");
double vitesseMario = double.Parse(Console.ReadLine());

Console.Write("Vitesse de Bowser (km/h) : ");
double vitesseBowser = double.Parse(Console.ReadLine());

Console.Write("Avance de Mario (en heures) : ");
double avanceMario = double.Parse(Console.ReadLine());

double temps = (vitesseMario * avanceMario) / (vitesseBowser - vitesseMario);

Console.WriteLine("Bowser rattrapera Mario après " + temps + " heure(s).");

    Exercice 3 - Terrain

    Console.Write("Longueur du terrain (m) : ");
double longueur = double.Parse(Console.ReadLine());

Console.Write("Largeur du terrain (m) : ");
double largeur = double.Parse(Console.ReadLine());

double perimetreMetres = 2 * (longueur + largeur);
double aireMetresCarres = longueur * largeur;

double perimetrePieds = perimetreMetres * 3.28084;
double airePiedsCarres = aireMetresCarres * 10.7639;

Console.WriteLine("Périmètre : " + perimetreMetres + " m");
Console.WriteLine("Périmètre : " + perimetrePieds + " pieds");
Console.WriteLine("Aire : " + aireMetresCarres + " m²");
Console.WriteLine("Aire : " + airePiedsCarres + " pieds²");

    Exercice 4 - Réservoir d'essence

    Console.Write("Capacité du réservoir (L) : ");
double capaciteReservoir = double.Parse(Console.ReadLine());

Console.Write("Consommation par kilomètre (L/km) : ");
double consoParKm = double.Parse(Console.ReadLine());

Console.Write("Destination : ");
string destination = Console.ReadLine();

Console.Write("Distance à parcourir (km) : ");
double distance = double.Parse(Console.ReadLine());

Console.Write("Quantité ajoutée à la fin (L) : ");
double ajoutEssence = double.Parse(Console.ReadLine());

Console.Write("Prix par litre ($) : ");
double prixParLitre = double.Parse(Console.ReadLine());

double essenceUtilisee = distance * consoParKm;
double essenceRestante = capaciteReservoir - essenceUtilisee;
double coutEssenceUtilisee = essenceUtilisee * prixParLitre;
double essenceApresAjout = essenceRestante + ajoutEssence;
double coutAjout = ajoutEssence * prixParLitre;

Console.WriteLine("Destination : " + destination);
Console.WriteLine("Essence restante à l'arrivée : " + essenceRestante + " L");
Console.WriteLine("Prix de l'essence utilisée : " + coutEssenceUtilisee + " $");
Console.WriteLine("Essence après ajout : " + essenceApresAjout + " L");
Console.WriteLine("Prix de l'ajout : " + coutAjout + " $");

    Note : si l'utilisateur doit faire un trajet plus long que la capacité du réservoir, il faut ajouter une condition pour gérer le cas où le réservoir est vide avant d’arriver.
